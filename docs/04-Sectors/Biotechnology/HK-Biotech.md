# 港股生物科技：基本面、估值、资金与事件识别

## 1. 研究对象与分层

不能把所有“医药股”视为同一资产：创新药商业化企业、尚未产生稳定产品收入的研发企业、CXO 服务商、医疗器械与传统药企的盈利结构截然不同。首先确定指数代码、样本成分、股票代码、上市币种、是否包含18A企业、权重以及自由流通市值；对龙头高权重个股、低流动性小盘股分别统计。板块上涨至少区分**权重拉动**、**广度改善**、**成交量放大**与**基本面预期变化**。

## 2. 价值形成：从管线而不是故事出发

对尚未形成稳定利润的创新药公司，可以采用风险调整后的净现值（rNPV）框架：`企业价值 ≈ Σ[各适应症未来现金流现值 × 阶段成功概率] + 净现金 − 未来资金缺口的稀释成本`。这是研究建模表达式，不是可以直接套用的精确估值公式。概率必须以适应症、阶段、终点、竞争格局和项目设计分别校准，不能用一个“创新药平均成功率”代替。商业化现金流进一步拆成患者规模 × 可治疗比例 × 市占率 × 实际净价 × 收款率，再扣除生产、营销、后续研发与税费。

**授权交易（BD）须拆项**：签约总额通常可能包含首付款、研发/注册里程碑、销售里程碑及未来销售分成。`名义总金额 ≠ 已到账现金 ≠ 会计确认收入 ≠ 项目净现值`。仅当合同原件、监管公告或公司披露明确了触发条件，才能在现金流时间轴上建模；合作伙伴的终止权、地域权利、分摊开发费用和授权范围同样影响价值。临床数据应优先检查主要终点、对照组、样本量、不良事件、亚组分析和随访时长；新闻标题不等于审批或商业化成功。

## 3. 三条可能的价格传导路径

**现金流重估**：临床结果/审批/授权改变某条管线的可实现现金流或成功概率 → 公司估值变化 → 相关企业的可比项目被重新定价。应逐公司检验公告日期和事件窗口收益，不能仅凭板块同时上涨判定存在共同催化。

**折现率与融资重估**：长期研发企业的价值受贴现率和融资条件影响。即使预期现金流不变，较低的资本成本在模型中可能提高远期资产现值；但港币股价还受到美元利率、汇率、市场风险溢价、流动性和实际融资折价等共同作用，简单用“一次降息”解释所有公司并不成立。

**仓位及流动性重估**：ETF资金、南向交易或再融资预期可能改变短期供需，推动价格再影响持有人风险预算。公开交易统计只能说明所观测的成交或持仓口径，无法单独识别最终买方动机；将‘资金先买入’与‘价格上涨后被动增加持仓市值’分开。

## 4. 可执行的事件归因方法

（1）固定 T0、T−5 至 T+5 的交易日窗口，以同币种计算个股及指数总回报；剔除停牌与复权干扰。（2）测算指数权重贡献 `贡献_i ≈ 期初权重_i × 区间收益_i`，同时记录上涨家数比例、成交额分位数和等权收益。（3）建立同日公告时间线，包括临床、BD、监管、融资、股东减持与行业指数调整，标注信息实际公开的时刻。（4）用港股大盘、其他医药子行业及利率/汇率变化构造对照；如需事件研究，以事前估计的市场模型测算异常收益，但需说明小样本及共同冲击局限。（5）以最新披露现金余额、经营净现金流与未来试验费用估计现金跑道：`现金跑道（月）≈ 可动用现金 / 月均净现金消耗`；净现金消耗不稳定时需用多情景，不能机械外推。

| 待验证假说 | 支持性证据 | 重要反证 |
| --- | --- | --- |
| 管线与BD驱动 | 多家公司的独立重大公告，相关标的超额收益集中 | 无相应公告或收益主要来自无关标的 |
| 折现率驱动 | 高久期研发型公司更敏感且利率预期同期变化 | 利率未变、成熟药企与研发企业反应并无差别 |
| 流动性驱动 | 成交与持仓口径一致、广度上升且持续 | 指数仅由少数权重股推动、成交没有放大 |

## 5. 风险、边界与结论格式

分别记录临床失败、审批延迟、价格竞争、医保及支付能力、商业合作终止、融资摊薄、汇率、流动性与治理风险。将**短期价格变化**、**中期盈利预期**和**长期管线现金流**作为三张不同的表，不用当日涨幅倒推出研发成功。事件卡的结论应按“已核验观察—候选解释—最强反证—尚缺数据”填写；不进行个股买卖建议。
