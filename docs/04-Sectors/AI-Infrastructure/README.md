# AI基础设施：资金传导、系统瓶颈和网络脆弱性

[← 行业](../README.md) · [光通信/CPO](Optical-Communications.md) · [二阶效应](../../05-Risk/Contagion/Second-Order-Effects.md)

> **类型**：产业系统研究与导航；**更新**：2026-09-21。历史讨论涉及AI资金链、核心节点、脆弱性与通信市场，但完整原文及2026年各公司经营数据尚未归档。本文的关系图是待核验研究模型，不是已证实的供货合同或投资结论。

## 1. 两张图分开：物理依赖与资金流向

**物理/技术链**：电力与数据中心选址 → 电网接入/备用供电 → 机房与冷却 → GPU/ASIC及HBM → 服务器、PCB/先进封装 → 交换ASIC、NIC、光/铜互联 → 集群调度/模型训练与推理。各节点不是简单的一条直线；电源、网络和计算可能互为约束，提升单卡性能不一定改善整个系统吞吐量。

**合同与现金链**：最终AI使用者支付软件/推理费用 → 云平台产生合同收入或作出资本开支承诺 → 系统集成与设备采购 → 零部件供应商形成订单、交货、收入确认和回款 → 扩产及融资。融资者、采购者、使用者可能不是同一主体，融资额、资本开支承诺、采购订单、设备收入和最终现金回收不应重复相加。

## 2. 需求测算从工作负载开始

业务需求分训练、推理和存储/检索：`每期总需求≈任务次数×平均计算量/任务`只是第一层估计；推理的峰值并发、上下文长度、批处理效率、量化/压缩、缓存命中和服务等级要求会使装机需求与总计算量不同。计算节点有效产出可写为 `理论峰值算力×设备利用率×软件效率×集群通信效率`，每个效率因子都需实测。网络拥塞、HBM容量、电力限制等可能产生乘数效应，不能对不同约束独立求和。

## 3. 五类关键节点及收入识别

| 模块 | 技术与采购单位 | 可观察经营信号 | 典型反证 |
| --- | --- | --- | --- |
| 计算/加速器 | 卡、板、整机、集群 | 实际交货、服务器利用率、客户资本开支 | 订单转延期、折价销售 |
| 存储与封装 | HBM堆栈、基板、封装产能 | 良率、认证、有效产出与单位成本 | 名义产能扩张但良率低 |
| 网络互连 | 交换端口、链路、网卡与光模块 | 端口代际、光口比例、系统验收 | 新拓扑减少交换层、铜代光 |
| 供电散热 | MW接入、功率密度、冷却能力 | 并网进度、PUE、冗余标准 | 电网接入拖延导致设备闲置 |
| 软件及最终需求 | 有效token/任务与服务收入 | 留存、单位任务成本、毛利与回款 | 使用量增长但收入质量恶化 |

不可直接将某GPU厂商整体营收增长乘以某一A股供应商历史配套比得出其未来订单。逐层确认技术路线、供应份额、客户认证、交货日期、价格变化及收入确认。

## 4. 核心性与脆弱性的网络科学建模

图中节点为真实产品/工艺/厂商，边应区分 `技术不可替代依赖`、`经核实采购/销售`、`物流与能源`、`信用/融资`，并标注权重、时点、方向、替代边。指标可以同时测：度与加权强度（连接数及业务量）、加权介数（跨路径中转重要性）、k-core（紧密内核）、最大流/最小割（系统实际吞吐瓶颈）、删除节点后的服务损失与恢复时长。**核心节点不等于最脆弱节点**：拥有多条平行替代边的高连接节点可能比较稳健，而低连接、唯一合格供应商的器件可能构成单点故障。

构建扰动试验：删除单一供应商、限制某类HBM、网络端口供给下降、并网延迟，分别重新求最大流和成本最小化，再比较替代路线及交付时间。模型权重缺失时展示范围和假设，不把算法中心性当作现实供应商市占率。

## 5. 资本市场的二阶与反向效应

第一阶段，终端服务需求影响云资本开支预期；第二阶段，设备交货与供应商扩产影响库存、现金转换周期和竞争；第三阶段，市场估值与融资成本影响企业可扩张速度，产能增长又可能压低产品价格。系统中可能出现‘需求很强但个别环节利润率下降’与‘股价先涨、收入后确认’的时间错位。连接[光通信](Optical-Communications.md)、[行业轮动](../../03-Markets/Equities/A-Shares/Industry-Rotation.md)及[二阶效应](../../05-Risk/Contagion/Second-Order-Effects.md)。

## 6. 最小证据包与更新方式

每一条产业关系至少标记产品型号、交易双方（如有公开证据）、技术依赖性质、证据发布日期、交货/收入时间、币种及来源链接；匿名链条仅作为研究假设。按季度更新终端需求、设备交付、关键瓶颈、单位成本、供应商毛利与库存；日内股价作为独立事件卡而不混入产业事实。重大预测必须写出基准、上行、下行三组明确假设和证伪阈值。
