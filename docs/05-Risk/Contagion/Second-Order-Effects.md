## 概念性研究框架

一阶效应描述事件对现金流或折现率的直接变化；二阶效应关注市场参与者对该变化的再反应，如风险预算调整、估值预期、再融资条件、供应链资本开支及拥挤交易；更高阶效应可能产生正/负反馈。

## 验证要求

针对每条传导链写清 `起点 → 作用主体 → 中间变量 → 滞后期 → 可观察指标 → 替代解释 → 失效条件`。仅观察到先后发生不足以证明因果。研究实例应连接到特定事件卡，并标识当时可获取的信息而非事后信息。
