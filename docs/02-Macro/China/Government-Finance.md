# 中国地方财政与融资：事权、预算、土地、债务的联动机制

[← 宏观与制度](../README.md) · [主权债务](../../03-Markets/Fixed-Income/Sovereign-Debt.md) · [风险传导](../../05-Risk/Contagion/Second-Order-Effects.md)

> **页型**：制度经济学的长期研究页，**更新日**：2026-09-21。本文中的历史制度分析以兰小欢《置身事内：中国政府与经济发展》（2021）提供的章节主题为阅读起点，模型部分属于本文原创整理；不将该书的历史描述或统计当作2026年已核实的政策、预算或债务现状。涉及当期政策变更时须另核查正式法规与财政披露。

## 1. 分析单位：先明确谁在花钱、谁在承担风险

中国经济中的政府投融资研究必须区分中央、地方不同层级及其财政账簿、地方国有企业、具有政府融资功能的实体，以及私人部门。地方政府名义上的事权、财权、实际执行权和可能承担的财务风险并不自动一致。分析一项基础设施项目时，分别记录：项目发起与审批主体、用地与资金来源、债务合同借款人、偿债现金流、是否存在明确且有效的担保或财政支持安排；不能仅因企业属于地方国资便将其全部负债视作法定政府债务。

## 2. 事权与财权之间的激励问题

《置身事内》上篇第一章讨论地方权力与事务，涵盖外部性、规模经济、复杂信息和激励相容；第二章讨论财税及土地财政，第三章讨论政府投融资与债务，第四章讨论产业投资。本文用一个四元组整理：`支出责任 E`、`可支配财政资源 R`、`上级转移/专项支持 T`、`可持续融资能力 F`。当经常性支出 E 的增长快于 R+T 时，可选行为可能涉及缩减支出、调整税费与资产处置、争取转移支付或融资，但每种选择都有制度和经济约束。不能把地方财政压力简单等同于某种必然行为。

外部性要求跨区域项目由更高层级协调；信息优势使基层更了解项目需求；激励相容要求获得收益、承担责任及监督的主体尽可能一致。研究财政体制时应同时观察居民公共服务、产业招商和项目绩效，不只看投资规模。以上是理论机制，具体事权划分仍以对应年份官方规则为准。

## 3. 分清收入性质和四类账簿

最重要的研究动作不是把所有带‘财政’字样的金额相加，而是标注口径：税收与一般公共预算；政府性基金中的相关收入和支出；国有资本经营收益；社会保险基金。土地使用权相关收入具有时间波动和专门的支出/扣除安排，不能直接等同于可自由支配的财政盈余。国企营业收入不等于利润，国企资产市值不等于可以立即偿债的现金；融资平台借款也不等于预算收入。对公开文件中的‘综合财力’需反查其计算定义，防止将转移支付、基金调入及同一项目现金流重复计数。

## 4. 土地、基础设施与房地产的两向传导

可检验链条之一：城市化与土地开发需求 → 基础设施及征拆支出 → 土地相关收入/项目融资 → 新建设施及地产开发 → 后续税基与债务偿付。反向链条：土地需求或地产交易减弱 → 土地相关收入变化 → 项目资本金与再融资能力变化 → 基础设施/工程企业应收账款与就业需求变化。任一箭头都可能被税收、财政转移、项目储备、政策安排、城市差异和时间滞后改变，不应当成所有地方的统一运行规律。

## 5. 项目现金流与债务服务覆盖

对一个可收费项目，`经营性现金流 = 收费收入 − 运营维护 − 税费 − 必要资本开支`；`DSCR = 可用于偿债现金流 / 同期合同约定本息支付`。对没有独立经营收入、依赖财政支付的公共项目，必须另评估相关预算安排是否明确、合法且可持续，不得虚构‘项目自偿性’。利率上升、建设延期、项目收入低于预测、资产不能出售和再融资窗口关闭可能同时发生，因此要做联合而非独立压力测试。

| 分析层 | 记录指标 | 可能的错误 |
| --- | --- | --- |
| 经常性财政 | 税收、转移支付、刚性支出、结余 | 将一次性土地收入永久化 |
| 基金和土地 | 总收入、成本扣除、净现金、时点 | 将毛收入当偿债可用现金 |
| 项目与实体 | 借款人、债务期限、项目回款 | 以政府关联替代合法担保 |
| 宏观外溢 | 工程订单、企业回款、就业及信用扩张 | 只计算投资需求不计债务与挤出 |
