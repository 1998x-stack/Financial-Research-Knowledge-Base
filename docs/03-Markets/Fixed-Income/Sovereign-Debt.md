# 全球主权债务：风险矩阵、再融资到期墙与利率冲击

[← 固定收益](../README.md) · [中国地方财政](../../02-Macro/China/Government-Finance.md) · [风险传导](../../05-Risk/README.md)

> **类型**：长期方法论。**更新**：2026-09-21。此处没有2026年完整、同口径的20国债务原始数据；不得将示例结果当作当前国别统计或风险排名。

## 1. 把三个风险区分开

**偿付能力**：中长期基本财政余额和增长能否支撑债务动态；**流动性/滚续风险**：即使净资产尚可，集中到期和市场融资受阻仍可能形成压力；**币种/货币制度风险**：外币负债、本币货币政策空间、通胀及资本流动约束并不相同。信用利差、汇率贬值、国内金融压抑、资本管制或再融资成本上升可能以不同组合呈现；‘债务/GDP高’单独并不能识别危机。

## 2. 统一口径的八维风险矩阵

| 维度 | 统一定义与单位 | 解释时的关键例外 |
| --- | --- | --- |
| 10Y收益率 | 对应本币名义10年期可交易国债，观察日、报价基准 | 倒挂与期限溢价；新债不能全部按10Y融资 |
| 政府债务/GDP | 同期、同口径总额或净额；中央/广义政府注明 | 中央与地方、社保及公共资产不可混用 |
| 财政赤字/GDP | 总余额及基本余额（排除利息）分别列 | 周期调整口径与一次性事项 |
| 实际利率 | 名义利率减预期通胀的近似，并注明期限 | 已实现通胀不等于当期预期通胀 |
| 外资持仓 | 非居民持有债券占比及币种 | 离岸托管、间接持有与本国机构风险 |
| 平均债务期限 | 加权平均剩余期限WAM，年 | WAM不等于加权平均重定价期限 |
| 本外币构成 | 按债务面值币种、对冲安排和法律条款 | 美元计价不一定等于实际未对冲美元敞口 |
| 利息/财政收入 | 统一预算口径下现金利息与收入 | 与应计利息、货币当局利润转移区分 |

矩阵只保留原始指标、数据可信度和缺失值，不产生未经说明的综合分数。数据源优先各国债务管理办公室/财政部、IMF财政数据库及国际清算银行；逐项登记发布日期、覆盖期与修订版本。

## 3. 债务动态的可审计恒等式

设 `b_t = 期末政府债务/GDP`，`r_t = 有效名义利率`，`g_t = 名义GDP增长率`，`pd_t = 基本赤字/GDP`，`sf_t = 存量流量调整/GDP`。在一致时点和单位下近似有：

`b_t = ((1+r_t)/(1+g_t)) × b_(t−1) + pd_t + sf_t`。

该式说明名义增长率、有效利率与基本财政余额共同决定债务率。实际研究还需考虑发行折溢价、外币债汇率重估、政府资产交易及统计口径。新发收益率不等于存量有效利率；不能用某天10年期利率替代下一年全部存量债的票息。

## 4. 2026—2035逐年再融资到期墙

对每个国家逐券获取 `ISIN / issue_date / maturity_date / currency / outstanding_principal / coupon_type / reset_date / coupon_rate / indexation / issuer_scope`。按法定到期日归集当年本金；对于短期国库券，要区分既有存量到期与未来滚动续发，否则会重复计入。浮息债在重定价日计入利率敏感现金流；通胀挂钩债按指数规则单列；回购、债务置换和再融资计划与确定的合同到期分开。

核心指标：`M_y = Σ_{i: maturity_i∈y} 尚未偿还本金_i`；`发行后新增年化利息近似 ΔI_y = Σ_{i∈y} 再融资金额_i × (假设新融资利率_i − 到期债当前年度化融资成本_i)`。第二式是**增量情景近似**，不包括票息日期、债券折价摊销、发行费用、原债在年内到期所造成的时间权重。严谨年度现金流为逐券逐付息日累计，不应直接把全年到期本金乘全年新利率。

## 5. 利率上升1个百分点的传导路径

采用三条平行情景：A 仅新发债利率整体上移100bp；B 新发利率上移100bp且浮息债下一重定价期同步改变；C 再加信用利差、汇率和融资数量的内生变化。比较 `ΔI_t = I_t(冲击) − I_t(基准)` 及 `ΔI_t/财政收入_t`，按1/3/5/10年报告时间路径。长WAM通常使存量固定利率债的账面利息传导更慢，但不消除市值损失、持有机构流动性压力与新增赤字融资成本。

**符号示例，非任何国家事实**：若某一年实际再融资本金为100单位，全年生效且加息1个百分点，则下一完整年度增量利息约1单位；若年中均匀再融资，当年增量利息约0.5单位。计算时必须写明本金单位、计息规则、债种和时点，不能把此示例填进国别表。

## 6. 跨国比较的特殊问题

本币发行国面临的通胀、汇率和利率渠道，不等同于外币发行国的外汇现金流约束；货币联盟成员与拥有本国货币的发行主体也应标识制度条件。日本等持有结构、央行持券及本国金融机构资产负债表，对市场冲击渠道重要；资源出口国必须测试大宗商品收入及本币汇率共振；地方债和国企债的政府支持假设应单独列或有负债，不在未经披露下直接等同法定中央政府债务。

## 7. 数据模式与质量控制

建议建立 `country_scope`, `security`, `cashflow_schedule`, `auction_curve`, `fiscal_series`, `fx_series`, `scenario`, `scenario_result`, `source_revision` 九张逻辑表。每张主键含国家+政府口径+币种+观察时点；到期墙须核对逐券合计与官方存量、拍卖替换/提前偿还、可回售债和法定日与统计年度的差异。发布每国的缺失覆盖率和‘可比/不可比’注释；无法取得完整逐券数据时仅能做期限桶情景，不得自造精确到期墙。
