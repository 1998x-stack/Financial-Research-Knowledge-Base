# A股行业轮动：宏观状态、盈利扩散与资金反馈

[← 股票市场](../README.md) · [2026-09-20 事件卡](../../../08-Events/2026/09/2026-09-20-A-Share-Industry.md) · [产业链](../../../04-Sectors/README.md)

> **页型**：常青研究主词条；**更新日**：2026-09-21；**时点声明**：2026-09-20 原对话仅有题目，尚未取得当周行业收益、成交及原始回复。本页提供可复用的完整分析框架，不冒充当周复盘结论。

## 1. 对象和可比口径

首先指定申万或中信行业分类及版本，固定周度窗口、交易日、行业样本、自由流通市值、复权和退市处理。行业指数收益既可能反映少数权重股，也可能是全行业普涨，应同时计算市值加权、等权、中位数收益和上涨家数。指数更新后需要以时间有效的成分映射，不能用今天的行业成员倒填过去的行业收益。

`行业周收益 = Π(1 + 行业日收益) − 1`；`相对收益 = (1 + 行业收益)/(1 + 基准收益) − 1`。这里的相对收益是可比较的定义，不是仅用两者百分点差在多期复利时近似替代。

## 2. 行情如何拆成可解释的三部分

对稳定盈利企业，一个研究用近似关系为 `股价变动 ≈ 盈利预期修正 + 估值倍数变化 + 分红/其他调整`；严谨的总回报与估值变化须统一口径。盈利预期变化要看未来4—8个季度一致预期的时间序列、订单/出货与毛利率，而不是事后把历史盈利增长当作股价催化。估值扩张要分辨无风险利率、股权风险溢价、成长久期、质量溢价和短期流动性。对于周期行业，应以中周期盈利、库存及资本开支分析，避免低谷高PE的机械解释。

建议将周度行业状态划分为四象限：盈利上修/下修 × 估值扩张/收缩，并单独标注尚无有效盈利预测的研发企业。行业上涨但盈利下修时，不能归因于‘基本面改善’；上涨且成交显著集中时，需评估风险偏好和拥挤度。

## 3. 宏观状态到行业的中间变量

宏观变量不直接决定行业涨跌，必须经过企业现金流或投资者定价渠道：实际利率与信用利差 → 企业融资成本和久期估值；需求/库存周期 → 订单、开工率与价格；财政投资 → 项目采购、订单确认及回款；汇率 → 出口收入与进口原料成本；全球科技资本开支 → 芯片、互联与设备采购。对每一条链记下**方向、预计滞后、利好受益方、成本承担方和可能的抵消变量**。同一宏观冲击可以同时改善收入和提高成本，不宜只保留一种方向。

## 4. 资金面：可观察的量与不能观察的动机

指数ETF申赎、两融余额、成交集中度、换手、个股大宗交易、南北向公开口径等是不同层级变量：申购不等于同量即时买入，成交额不是净流入，市值变化也不是新增资金。所谓‘主力净流入’往往依赖成交方向估算，必须披露方法，不能当成真实资金账户流。机构与个人的仓位变动只有在合规公开披露的频率与样本中才可推定，避免把即时行情叙事等同于资金来源识别。

拥挤度用多个独立指标交叉检验：过去20/60日相对涨幅分位、成交占全市场比例、换手率分位、估值分位、盈利预测分歧、行业内部收益相关性和集中度。拥挤并不自动意味着下跌，它描述了对同向风险冲击可能更敏感的仓位结构。

## 5. 从‘先跌后涨’到轮动：辨别日内与跨周过程

日内研究应记录分钟级指数、行业贡献、成交结构、可验证新闻发布时间及衍生品变化。‘下午反弹’可能由权重股修复、行业扩散或指数成分股反转驱动；需要按每15—30分钟计算贡献，而不能从收盘涨跌倒推原因。跨周轮动至少区分：旧主线内高低切换、跨行业盈利扩散、利率驱动的风格轮换、政策预期及再平衡。分别验证领先行业下跌是否伴随整体风险偏好下降，还是落后行业独立改善。

## 6. 产业链与二阶反馈

例如AI算力投资增加可能使网络、存储、散热和供电环节收到不同步的订单；下游资本开支削减也可能先影响远期指引再影响上游订单。股价提前上涨之后，供应商融资条件改变、资本开支响应和新产能释放又可能反向改变未来盈利。应将该机制作为待检验链条，关联[AI基础设施](../../../04-Sectors/AI-Infrastructure/README.md)与[二阶效应](../../../05-Risk/Contagion/Second-Order-Effects.md)，而非把同期行业共同涨跌自动判为传导证据。

## 7. 周报数据表与判别规则

| 必填字段 | 解释 | 关键边界 |
| --- | --- | --- |
| window, benchmark, taxonomy_version | 固定比较基础 | 全部行业同窗口、同分类版本 |
| weighted_return, equal_return, breadth | 判断权重与广度 | 处理停牌、上市和成分变动 |
| volume_share, turnover_quantile | 交易热度 | 不能单独推断净买方身份 |
| eps_revision, earnings_dispersion | 未来盈利预期变化 | 避免使用事后回填一致预期 |
| valuation_quantile, risk_free_rate | 估值与折现背景 | 不同行业不能机械比较静态PE |
| catalysts, counterevidence, data_asof | 催化与反证 | 公告发布时间早于相应行情才可能构成该时点解释 |

形成三种条件情景而非预测具体涨跌：**盈利扩散**要求订单、盈利预测和市场广度共同改善；**纯估值重估**要求基本面变化弱、折现或风险偏好指标较强；**流动性逆转**要求成交退潮与原先高度集中的标的承压。每种情景记录不成立的证据，避免事后无论行情如何都能解释。

## 8. 来源与已知空缺

事件数据待登记真实来源：交易所行情、指数编制与历史成分、上市公司公告、正式宏观发布及可得的一致预期快照。目前未取得2026-09-20对话正文或该周全行业数据，因此本页**没有**对该周行业表现、某板块‘最强’或具体轮动顺序作事实断言。
