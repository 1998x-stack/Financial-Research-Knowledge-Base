# 编辑、核验与公开发布规范

[← 指南](README.md) · [分类体系](Taxonomy.md)

## 文档结构

知识页：`问题与范围 → 关键概念 → 机制/模型 → 证据与数据时点 → 反证与替代解释 → 风险/边界 → 关联页面 → 来源与更新记录`。

事件页：`发生时间和市场 → 已核验观察 → 可检验解释假设 → 反向证据 → 关联知识页 → 待补资料`。

周报：`覆盖期 → 本周问题及链接 → 跨主题发现 → 未决事项 → 原始记录覆盖率`。

可直接复制 [知识页模板](../_templates/Topic.md)、[事件模板](../_templates/Event.md) 和 [周报模板](../_templates/Weekly.md)。

## 证据等级与时间

- **已核验事实**：可复核的原始公告、原始数据或有明确来源的记录；写出发布日期、覆盖市场、统计口径及引用位置。
- **来源主张**：将观点归于明确作者/机构，不将推论写成确定事实。
- **研究假设**：列出可证伪指标、替代解释和可能改变判断的条件。
- **待核验**：仅有题目、聊天摘要或未核实传闻，绝不虚构数字、行情、因果证据或原始对话。

数据如跨日期必须明确 `事件发生日`、`数据截至日`、`页面更新日`；历史数据不得直接写成今天市场情况。风险矩阵的维度、口径、缺失值、单位和假设应记录清楚；模型输出与观察值分开标注。引用外部文献简短概述与链接，不复制受版权保护的完整作品或长篇段落。

## 公开仓库与隐私

仓库当前公开。上传前检查：聊天中是否有身份证、账户、个性化投资记录、未公开研究、API keys、私密附件、整本商业书籍、未经授权的第三方内容。发现以上内容只记抽象主题与本地来源占位，不上传原文。私密研究另放私人仓库，且历史 Git 版本可能仍会保留已提交内容。引用 PDF/EPUB 时优先只列书目、章节和自己的短篇研究笔记。

## 增量与纠错

同一主题新增研究先读现有页面，避免新建 `v2/final/new` 重复文件；新事实以日期、来源、证据等级追加。重大结论变化写 `更新记录`，不静默覆盖旧结论；目录移动更新入链并保留 Git 提交历史。每周检查链接、日期、孤儿页面、重复词条和待核验条目。
