# Wiki编辑规范：完整章节、时点证据与质量门禁

[← 指南](README.md) · [分类体系](Taxonomy.md) · [知识地图](Topic-Map.md)

> **目标**：知识主页不是聊天标题列表。每个研究主词条应在不阅读原始对话的情况下，足以理解研究问题、概念、传导模型、应用、数据、反证及局限。导航页、事件卡、周报和来源台账是不同的页面类型，不通过机械填字数替代它们的功能。

## 1. 区分四种页面类型

| 类型 | 使命与应具备的内容 | 不应做的事 |
| --- | --- | --- |
| 常青研究主词条（canonical） | 定义/范围、可运行逻辑、公式或概念模型、示例、指标定义、竞争假设、反证、数据方案、时点、来源、交叉链接 | 只有提纲、只有待补清单、复制聊天原文充篇幅 |
| 事件卡（event） | 发生/披露时点、观测事实、受影响资产、竞争解释、可检验观测、当时与事后信息、事件后复核 | 在缺乏行情和公告原件时编造当日原因 |
| 周度索引（weekly） | 明确的日期范围、当周新增主题、各篇研究修订、证据覆盖率、未决事项和链接 | 复印所有主题正文或将两个自然周混成一个 |
| 目录与来源页 | 清晰层级、双向导航、版本化书目、授权与时点 | 为追求篇幅把空泛内容填进README |

## 2. 主词条最小完成标准

必须回答：**研究对象是什么？适用何种市场和时间？最重要的机制是什么？通过哪些中间变量传导？公式或单位是否完整？哪些观察可以支持/推翻？数据和资料从何而来？仍有哪些无法确认？**。机制至少包含一条显式因果链和滞后；定量部分至少说明分子分母、单位、频率、观察时点与示例是否为假设；现实案例要标真实来源、发布时间及其代表性。专业内容鼓励分层深入，不规定统一字数；需要更多实质内容时扩写模型、敏感性和证据，而非重复措辞。

主词条建议章节：`摘要与边界 → 定义/分类 → 机制/数学或流程模型 → 具体案例/产业映射 → 数据与度量 → 相反观点与识别 → 风险/压力测试 → 来源和可追溯更新`。若资料只有标题，就把可验证的一般理论写成**独立研究整理**，同时保留‘原始对话待补’说明；不得伪装成已恢复原答。

## 3. 证据等级与三重时间轴

**观察事实**：原始公告、官方统计或可复核数据，记录发行方、文档版本、样本期与提取时间；**文献观点**：明确是谁在什么研究范围下提出，避免转换为普适定律；**模型推断**：明确假设、参数和误差；**研究假说**：有可证伪预测；**待核验**：缺失原始证据或仅有聊天题目。记录 `occurred_at/observed_period`、`published_at/available_at` 与 `retrieved_at/page_updated_at`，确保行情发生后才发布的材料不会被误用于事前因果解释。

相同指标比较需统一市场、币种、复权、分类版本、会计期间及主体统计边界。缺失值不得填‘0’冒充已知。主权债务的中央和广义政府口径、公司的订单和收入、港股南向成交和持仓、原始价与复权价尤其需明示区别。

## 4. 研究质量检查

**反事实与竞争假设**：不止写支持证据，每一核心结论至少列一个有力的替代机制和一条可能推翻主张的观察；若无法识别因果，明确只发现相关。**算术审计**：单位、日期、现金流时间权重、币种和财务勾稽需能独立重算。**模型审计**：写清适用范围、边界条件、成本与约束、样本内外差异。**文献审计**：区分原始资料内容、研究者改写和新推论；与原文不一致时直接标出差异而非暗中修正。

## 5. GitHub更新流程

先定位canonical页面，读取已有正文与链接；新增主题观点融入相应章节，新增时点事实写入唯一事件卡；周报只记录本周的文档变更和研究增量。重大结论修订在页尾写`YYYY-MM-DD：旧论断 → 新证据 → 修正 → 仍未解决`。PR审查关注：相对链接可达、未出现相同主题镜像页、数据与时点清晰、Markdown表格正常、匿名源未伪装证据、目录与相关词条的双向链接有效。仓库若暂未配置自动化测试，不得声称CI已通过。

## 6. 公开仓库、隐私与版权

当前仓库是公开仓库；不可公开私人账户、个人持仓、原始私密聊天、API密钥、未授权的整本PDF/EPUB、付费报告及不具备转载权的数据集。书籍用于学习时优先记录书目、章节、必要的简短概述及原创笔记，不复制大段原文。若需要全文聊天归档，应先确认公开范围并对隐私做人工检查，历史提交记录可能留存曾误上传的信息。

## 7. 当前覆盖说明

2026-09-21起，知识库中的主要研究词条逐步从提纲升级为完整章节。具体市场事件如2026-09-20 A股与2026-09-21港股生物科技，完整对话及当天时点证据尚未获取，故对应事件卡保持待核实状态。此处的质量标准不允许把机制性长文冒充已完成当日实证归因。
