## Wiki 阅读方式

**主词条**提供自足的概念定义、机制、公式、研究用案例、数据方案与限制；**事件卡**记录可以核实的某天具体观察与竞争假说；**周报**以自然周组织链接，不复制正文；**来源台账**说明文献年份和数据覆盖。一个主题有唯一canonical文档，事件引用该文档而不是到处复制研究长文。

## 维护方法

按[完整章节质量规范](docs/00-Guide/Editorial-Policy.md)先审已有主词条，再将新发现融入相应章节，事件发生时补唯一事件卡及证据日期，最后在周报追加研究增量。重大结论更正保留修订记录和Git提交历史。此知识库用于学习和研究，不是个性化投资建议。
