## 阅读路径

- **按主题找**：从 [知识库首页](docs/Home.md) 进入宏观、资本市场、产业链、债券、风险、量化与数据等分层分类，再进入可持续更新的主题页。
- **按时间找**：从 [每周研究索引](docs/09-Weekly/README.md) 跳转当周事件及其对应主题页；事件和周报是入口，不替代主题正文。
- **按研究问题找**：从 [研究问题索引](docs/00-Guide/Topic-Map.md) 查看跨主题研究链路。
- **按证据找**：每个分析页须标识数据时点、证据状态与来源；见 [来源台账](docs/10-Sources/Source-Ledger.md)。

## 分类原则

1. **一个知识点只有一个主页面（canonical page）**：同一研究对象的长期机制、定义与核心框架写入对应主题页；相关页面只放摘要和链接。
2. **主题与时间分开**：`03-Markets/` 等放可积累知识；`08-Events/` 放某日的市场事件；`09-Weekly/` 放周度导航；`90-Archive/` 只存允许公开的原始资料索引。
3. **逐层嵌套、不过度拆分**：一级领域 → 二级市场/行业/机制 → 三级研究对象 → Markdown 页面；每层 `README.md` 是该层的导航页。
4. **来源与推断分开**：`已核验事实 / 来源观点 / 研究假设 / 待核验` 分开标记；不得以聊天标题冒充完整研究报告。
5. **面向公开仓库**：当前仓库为 public。不要提交私密聊天全文、账户数据、个人身份信息、未经许可的书籍全文或付费研究报告；这里只记录可公开的原创概述和外部文献书目信息。

## 当前收录边界

初版仅根据当前会话中可见的项目历史**标题与少量摘要**建立主题入口。对 2026-09-20 的 A 股行业分析及 2026-09-21 的港股生物科技讨论，现有可见信息不足以还原当时完整论证，相关页面会明确标注 `待补原始对话`。没有将其写成已验证的市场事实。2026-09-15 至 2026-09-21 为第一批指定整理窗口；窗口外可见的早期研究另设导航而不混入该周正文。

## 维护方式

新问题先在 [分类表](docs/00-Guide/Taxonomy.md) 找主页面，再追加「问题—机制—证据—反证—未决问题」，有日期的市场变化另写事件卡并在周报中建立入口。所有新增/修订使用相对 Markdown 链接，并以 PR 或 commit 保留修订历史。
